# 🚀 Installation

### Termux (Android)

```bash
termux-setup-storage
pkg update -y && pkg upgrade -y
pkg install git nodejs -y
git clone https://github.com/sovereignempirex-ux/sovereignx-core
cd ~/sovereignx-core
npm install
npm start
```
